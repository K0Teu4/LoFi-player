# ORBITA · Tape Radio

Бесконечное генеративное лоу-фай радио в виде кассетного стола. Вся музыка синтезируется
в браузере в реальном времени: ни одного аудиофайла, только Web Audio API, математика и плёнка.

**Живая версия:** https://k0teu4.github.io/LoFi-player/

## Что это

- **Стол с кассетами.** Десять «авторских» треков на десяти движках (tape, piano, 8-bit,
  dub, synthwave, bossa, music box, phonk, jazz, techno) плюс кассета вашей стороны.
  Кассеты можно перетаскивать, бросать в окно плеера, пересыпать двойным кликом по столу.
- **Бесконечное радио.** Кнопка RADIO (или клавиша R) генерирует новые треки на лету из
  seed: один seed = один уникальный трек (аккорды, мелодия, темп, движок, название).
  Ссылкой с `?seed=…` можно поделиться — у друга зазвучит тот же трек.
- **Студия MY SIDE.** Петля-аккомпанемент на выбор из десяти движков, тональность,
  темп, сетка нот на два такта и пэды пентатоники. Записанную сторону можно сохранить
  как кассету и скачать в WAV.
- **Экспорт WAV.** Честный офлайн-рендер через OfflineAudioContext: тот же звуковой граф,
  нормализация пика до −1 dB, фейды 10 мс / 400 мс, 44.1 кГц / 16 бит / стерео.
- **Дневник прослушивания.** На вкладыше копится статистика: сколько треков и времени
  выслушано, какая кассета любимица. На этикетках — библиотечные штампы «×N».
- **PWA и офлайн.** Service worker кэширует оболочку, сайт работает без сети и
  устанавливается как приложение.
- **Onboarding.** При первом визите — интерактивный тур с прожектором: кассета → PLAY → REC.
